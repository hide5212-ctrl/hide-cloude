# 座席くじ

机の並びを選んで、参加者に座席をランダムで割り当てるアプリです。

- **Web 版** — `index.html` をブラウザで開くだけで動きます（ビルド不要・サーバ不要）。iPhone / iPad の Safari に最適化してあり、ホーム画面に追加するとアプリとして全画面で起動し、オフラインでも使えます。
- **iOS ネイティブ版** — `ios/` に SwiftUI の Xcode プロジェクトがあります。詳しくは [ios/README.md](ios/README.md) を参照してください。

## 机と席の並び

用途に合わせて 5 種類から選べます。切り替えると席数と席番号の付け方も変わります。

| 並び | 設定できる項目 | 向く場面 |
| --- | --- | --- |
| **コの字** | 上辺・左辺・右辺の人数 | 会議、研修。開いた側にスクリーンを置く |
| **ロの字** | 上辺・右辺・下辺・左辺の人数 | 討論、少人数の会議。全員が中心を向く |
| **対面（長机の両側）** | 片側の人数、端の席（0〜2） | 四角い長机に向かい合って座る配置 |
| **教室（スクール形式）** | 横に並ぶ人数、前後の列数 | 授業。全員が前を向き、ひとりに机ひとつ |
| **島型（グループ）** | 島の数、1 島の人数 | グループワーク、懇親会 |

並びを変えると席の位置の意味が変わるため、固定席は解除されます。
各並びの人数設定は別々に覚えているので、行き来しても入れ直す必要はありません。

## できること

- **ランダム抽選** — 参加者を各席に無作為に割り当てます（Fisher–Yates シャッフル）。
- **座席の固定** — 特定の人を決まった席に固定できます。固定された人はそのままで、残りの人だけが抽選対象になります。人数の制限はなく、1 人でも複数人でも固定できます。
  - 席カードを**クリック**すると、その席の人を固定／解除できます。
  - 右の「固定席」パネルから、人と席を選んで指定することもできます。
- **配置の変更** — 上辺・左辺・右辺の席数を個別に設定できます（初期値は 上辺 4・左辺 5・右辺 5 の合計 14 席）。
- **参加者の編集** — 1 行 1 名で入力します。初期状態は空なので、手持ちの名簿をそのまま貼り付けてください。
- **2 つの表示** — 「見取り図」（机と席の配置図）と「席順リスト」（01→ の一覧）を切り替えられます。見取り図は枠に入りきらないときだけ自動で縮み、スマートフォンでもスクロールなしに全体が見えます。
- **クリア** — 2 種類あります。
  - **席をクリア** … 抽選結果と固定席を消して席を空にします。参加者リストは残るので、そのまま抽選し直せます。
  - **参加者も空にする** … 参加者リストごと消します。席の配置（上辺・左辺・右辺の数）は残ります。
- **結果の書き出し** — テキストとしてコピー、またはそのまま印刷できます。
- 入力内容と抽選結果はブラウザの localStorage に保存され、再訪時に復元されます。

## 席番号の付け方

並びごとに決まっており、画面の見取り図の下にも表示されます。

| 並び | 採番の順 |
| --- | --- |
| コの字 | 入口側の左から時計回り（左辺 → 上辺 → 右辺） |
| ロの字 | 入口側の左から時計回り（左辺 → 上辺 → 右辺 → 下辺） |
| 対面 | 奥側の左から右へ、続いて手前側の左から右へ、最後に端の席 |
| 教室 | 前の列の左から右へ、それを後ろの列へ繰り返す |
| 島型 | A 島から順に、島ごとに奥側の左から時計回り |

コの字（上辺 4・左辺 5・右辺 5）の例:

```
        上座
   06 07 08 09        ← 上辺（左 → 右）
 05 ┌─────────┐
 04 │         │
 03 │  中央   │  10 11 12 13 14   ← 右辺（奥 → 手前）
 02 │         │
 01 └─────────┘
        スクリーン／入口
```

## 参加者が席数と一致しない場合

- 参加者 < 席数 … 余った席は「空席」として表示されます。
- 参加者 > 席数 … 警告を出し、席数を増やすまで抽選できません。

```sh
open index.html      # macOS

```

## 使い方（iPhone / iPad）

`index.html` を **https で配信** すると、ホーム画面に追加してアプリのように使えます。
GitHub Pages を使うのが手軽です。

1. GitHub のリポジトリで **Settings → Pages** を開く
2. Source を「Deploy from a branch」、Branch をこのブランチ（または `main`）の `/ (root)` に設定して保存
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPhone / iPad の **Safari** で開く
4. 共有ボタン → **「ホーム画面に追加」**

ホーム画面から起動するとアドレスバーのない全画面表示になり、Service Worker（`sw.js`）が
一式をキャッシュするので **電波の届かない会場でも起動できます**。

> Chrome など Safari 以外のブラウザからは「ホーム画面に追加」してもアプリとして起動しません。
> iOS の仕様なので、必ず Safari で開いてから追加してください。

画面ごとの見え方:

見取り図は**枠に入りきらないときだけ全体を縮めて収める**ので、どの端末でも横スクロールは起きません。
スマートフォンでは画面の高さにも合わせるため、下にスクロールしなくても図の全体が見えます。
席カードは小さめの寸法に切り替わり、名前は2行まで折り返して省略せずに表示します。

既定はどの端末でも見取り図です。名前をまとめて読みたいときは「席順」に切り替えてください
（01→ の一覧になります）。どちらの表示でも席を**タップ**すればその人を固定／解除でき、
表示の切り替えは記憶されます。

### iPhone なのに PC 版のレイアウトになるとき

このページは「ブラウザから渡された幅」でレイアウトを決めていますが、次の場合は
iPhone でも幅が PC 並みに報告されます。

- Safari の**「デスクトップ用Webサイトを表示」**が有効になっている（会社支給端末では既定で入っていることがあります）
- ページが別サイトの表示枠（iframe）の中に埋め込まれている

そのため描画幅だけでなく `screen.width`（端末そのものの画面幅）も見て、
**小さいほうを採用**するようにしてあります。上記のどちらであっても iPhone では
スマートフォン向けのレイアウトになります。

それでも PC 版で開きたい／逆に戻したいときは、上部の**「見取り図」「席順」**を
自分で切り替えてください。一度切り替えると、その選択が記憶され画面幅で上書きされません。

Safari の設定そのものを戻すには、アドレスバー左の **ぁあ** →「デスクトップ用Webサイトを表示」を
オフにするか、設定 → Safari → デスクトップ用Webサイトを表示 で確認してください。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体（HTML / CSS / JavaScript を 1 ファイルに同梱）。並びは `LAYOUTS` に 1 つずつ定義してあり、追加も同じ形でできます |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面設定 |
| `sw.js` | オフライン用の Service Worker |
| `icon-180/192/512/1024.png` | アプリアイコン |
| `ios/` | SwiftUI 版の Xcode プロジェクト |

外部ライブラリは使っていません。Web フォント（Google Fonts）だけをネットワークから読み込みますが、
読み込めない環境ではシステムフォントにフォールバックします。
