いつ 送る？

📧 Gmailに自動で届くようにする（Google Apps Script・5分）
  1. script.google.com で 新しいプロジェクトを作る
  2. 下のコードを コピーして、エディタの中身と 差しかえる
  3. 右上の「デプロイ」→「新しいデプロイ」→種類はウェブアプリ
  4. 「次のユーザーとして実行」＝自分、「アクセスできるユーザー」＝全員 にして デプロイ
  5. 表示された ウェブアプリのURL（/exec で終わる）を 上の欄に 貼る
  6. 保護者のメールアドレスを 入れて「テスト送信」
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  MailApp.sendEmail({
    to: d.to,
    subject: d.subject || 'さんすう学習の記録',
    body: d.text + '\n\n--\nまいにち さんすうチャレンジ'
  });
  return ContentService.createTextOutput('ok');
}

※ 初回デプロイ時に Googleの確認画面が出ます。「詳細」→「（プロジェクト名）に移動」で許可してください。

💬 Discord（LINEのように スマホへ すぐ届く）
  1. 保護者のDiscordで サーバーを作る（無料・自分一人でOK）
  2. チャンネルの⚙️→「連携サービス」→「ウェブフックを作成」
  3. 「ウェブフックURLをコピー」して 上の欄に 貼る
  4. スマホのDiscordアプリで 通知をONにしておく

Discordの場合、メールアドレスは いりません。
