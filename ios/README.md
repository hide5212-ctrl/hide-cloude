# コの字席くじ — iOS ネイティブ版（SwiftUI）

Web 版（リポジトリ直下の `index.html`）と同じ機能を SwiftUI で書いたものです。

- 対応 OS: **iOS 17 以降**（iPhone / iPad 共用）
- 外部ライブラリなし。標準フレームワークのみ

## 開く・動かす

```sh
open ios/KonojiSeat.xcodeproj
```

Xcode で開いたら、上部の実行先で **シミュレータか実機**を選び ⌘R で起動します。

### 実機に入れる場合

1. プロジェクト設定 → **Signing & Capabilities** を開く
2. **Team** に自分の Apple ID を設定する（Xcode → Settings → Accounts で追加）
3. **Bundle Identifier** を自分だけの文字列に変更する
   （初期値は `com.example.konojiseat`。他の人と重複すると署名できません）

無料の Apple ID でも実機で動かせますが、**7 日で有効期限が切れる**ため
期限が来たら Xcode から入れ直してください。期限のないアプリにするには
有償の Apple Developer Program（年額）が必要です。

> 当日ひとまず使いたいだけであれば、Web 版を Safari で開いて
> 「ホーム画面に追加」するほうが手間がかかりません（[../README.md](../README.md) 参照）。

## 画面

| 表示 | 内容 |
| --- | --- |
| 見取り図 | 机をコの字に描き、その外側に席を並べた配置図。iPad と iPhone 横向きの既定 |
| 席順 | 01→14 の一覧。コの字は横に広く iPhone の縦画面に収まらないため、こちらが既定 |

上部のセグメントでいつでも切り替えられます。どちらの表示でも、**席をタップ**すると
その人をその席に固定／解除できます。固定した人は抽選から外れ、残りの人だけが入れ替わります。

右上のボタン:

- **共有** — 座席表をテキストで書き出し、メールや LINE などに渡せます
- **設定** — 参加者（1行に1名）、上辺・左辺・右辺の席数、固定席の一覧、クリア

設定の下部に 2 種類のクリアがあります。**席をクリア**は抽選結果と固定席だけを消して
参加者リストを残し、**参加者も空にする**は名簿ごと消します。参加者の初期値は空です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `KonojiSeat/SeatingModel.swift` | 席の並び、抽選、固定、保存。画面を持たないロジック |
| `KonojiSeat/RoomView.swift` | コの字の見取り図 |
| `KonojiSeat/RosterView.swift` | 席順の一覧 |
| `KonojiSeat/SettingsSheet.swift` | 参加者・席数・固定席の編集 |
| `KonojiSeat/ContentView.swift` | 全体の組み立てと抽選ボタン |
| `KonojiSeat/Theme.swift` | Web 版と共通の配色 |

席番号は Web 版と同じく**入口側の左から時計回り**（左辺 → 上辺 → 右辺）です。
設定は `UserDefaults` に保存され、次回起動時に復元されます。

## 注意

このプロジェクトは macOS / Xcode の無い環境で書き起こしたため、**コンパイルによる動作確認はできていません。**
プロジェクト構成（`project.pbxproj` の参照整合性、ソースのビルドフェーズ登録、アセットカタログ、スキーム）は
静的に検証済みですが、Xcode で最初にビルドしたときに型エラーが出る可能性は残ります。
その場合はエラー内容を教えていただければ修正します。
